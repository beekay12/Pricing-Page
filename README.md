⚡ AutoFlow - Modern Pricing Page Interface 🚀
A sleek, responsive, and dark-themed Pricing Plans Interface designed for AutoFlow workflow automation platform. It features an interactive deployment toggle switching seamlessly between Cloud Hosted and Self-Hosted tiers with dynamic price updates.

🎨 Dark Mode UI: Designed with a refined dark color scheme and modern typography.

🔄 Dynamic Hosting Switcher: Toggle between Cloud Hosted and Self-Hosted options in real time.
